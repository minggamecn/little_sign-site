2. 保存在设备上的内容

每日卡牌、笔记、意图、已保存的解读、决定与状态、轮盘选项、心情与使用信号、主题和语言设置保存在设备上。应用生成一个本地安装标识，使抽牌结果保持一致；它不是广告标识。无需创建账号即可使用访客核心功能。

这些本地记录不会自动同步到我们的服务器。当前版本没有云端日记备份。我们不使用广告或分析 SDK 来上传这些记录。不要仅凭退出账号就认为设备数据已清除。

3. 邮箱账号与服务记录

当你注册或登录时，Supabase 及验证码邮件服务会处理你的邮箱、验证码验证、账号标识和登录会话，以验证身份并提供需要登录的功能。登录会话保存在设备上；验证码不会保存到日记中。

我们在服务器保存与账号关联的 AI 请求日期和次数，以执行使用限制并控制滥用。这些计数不包含你的问题、答案或笔记。

4. 可选 AI 问题

当你明确提交自定义 AI 问题时，你输入的问题、可选背景和所抽卡牌的信息会经由我们的 Supabase 服务发送给 DeepSeek 生成解读。问题中可能包含你自行输入的个人信息，请不要填写你不希望被处理的敏感信息或他人的私人信息。

我们不会把邮箱、账号标识、私人笔记、历史记录或心情信号加入 AI 提示词。账号仍用于在我们的服务上验证请求。答案返回应用，只有当你选择保存时才会写入本地历史。应用后端不会将问题和答案写入日记数据库，也没有主动记录问题正文的日志。服务商的运行日志、保留与处理可能独立于此流程。

我们不将你的本地日记用于训练 AI。本政策不承诺 AI 服务商对已提交文本提供零保留或不用于训练的处理；这些条件需以适用的 API 服务协议和已配置的设置为准。你可以不使用 AI，继续使用离线卡牌和预设情景。

5. 分享、照片与设备权限

当你主动导出或分享卡牌时，应用会创建图片并将它交给你选择的系统分享应用，或保存到照片库。当前卡牌分享排除私人笔记、意图和自定义问题。接收方及你选择的应用会按自己的规则处理已分享的图片。

保存图片时，旧版 Android 可能请求存储权限，iOS 可能请求添加照片的权限。应用不需要读取整个照片库，也不通过核心功能收集联系人、精确位置、摄像头或麦克风内容。你可以在系统设置中管理权限。

6. 服务商、网站与网络信息

Supabase 提供身份验证、数据库和应用后端。邮件服务负责发送验证码。DeepSeek 处理你提交的 AI 问题。网站通过 GitHub Pages 托管。网络服务商会收到处理连接所需的 IP 地址等网络信息，并可能处理请求时间、浏览器或设备信息和安全日志，用于运行、保护和诊断服务。

网站本身不设置 Cookie，也不在浏览器中保存数据；删除申请页只会打开你的邮件应用并预填内容，网站不会自行发送任何信息。网站没有添加广告或营销跟踪。托管平台可能使用其自身的安全或访问控制 Cookie。通过邮件联系我们时，你的邮箱和所提供内容会由邮件服务处理。

我们不出售个人信息。除提供服务的服务商、你主动选择的分享接收方，以及法律要求或保护服务安全所必需的披露外，我们不会主动披露你的记录。处理可能发生在你所在国家以外。有关服务商的说明：Supabase · DeepSeek · GitHub.

服务商面向自身用户的隐私政策不一定覆盖通过 API 提交的数据；Little Sign 的本政策及适用的服务协议共同说明相应处理。

7. 保留与删除

  • 本地记录保留到你删除记录或使用设置中的“清除本机数据”。卸载、设备丢失或重置也可能导致记录丢失；导出的图片和其他副本需要另外删除。
  • 账号记录保留到你删除账号。你可以在应用设置中使用“删除账号”，或按照删除账号页面的说明通过邮件申请。应用内删除经验证和确认后立即执行；邮件申请以发件邮箱核实归属，我们在收到可核实请求后 5 天内完成并回信确认。两种方式都会删除账号、关联登录记录及每个账号的使用计数，并通过已部署的数据关系删除其他关联记录。退出登录或清除本机数据不会删除账号。
  • 从应用删除账号时，该设备上可识别为属于该账号的 AI 历史会被删除。访客记录、旧版未归属记录和其他账号记录保留。我们无法擦除任何设备上的本地副本；请在每台设备上分别清除数据。
  • 使用计数在新一天请求时重置；成功处理请求时会清理超过两个日历日的旧计数。此清理由请求触发，并非定时保证。删除账号会移除其计数；不包含账号标识的全局计数保留。
  • 服务商日志、备份及已发送的 AI 文本可能按适用协议继续保留，用于安全、滥用防护、服务运行或法律义务。即时账号删除不保证抹除这些副本。有关适用于你请求的保留期限或删除协助，请联系下方邮箱。我们不为追踪删除而创建新的服务器账号记录。

8. 安全、选择与权利

账号和 AI 请求通过 HTTPS 传输。后端验证账号权限，管理密钥不会放入应用或网页。本地存储依赖设备和应用沙盒保护，并不提供独立的加密日记保险箱。请保护设备和邮箱；没有任何系统能保证绝对安全。

你可以使用访客模式、选择不提交 AI 问题、退出账号、管理权限、删除本地记录或申请删除账号。根据所在地法律，你还可能享有访问、更正、获取副本、删除、限制处理、反对处理或撤回同意等权利，以及向监管机构投诉的权利。我们可能需要验证身份；不会要求你发送验证码或密码。

行使权利或请求帮助：ming.life@foxmail.com. 帮助与联系.
